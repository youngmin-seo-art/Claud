## 6.1. 하이브리드 PoC 테스트베드 구축 아키텍처

고객사(ITS 컨버젼스)가 행정안전부, 소방청, 경찰청, 지자체 등 공공 발주처 평가위원단 앞에서 기술적 완결성을 시현할 수 있도록 **옵션 A (S/W 가상 시뮬레이션 + 실물 H/W 연동 하이브리드 모델)** 테스트베드를 구축합니다.

```
[1. 가상 시뮬레이션 환경 (Software Environment)]
┌──────────────────────────────────────────────────────────────┐
│ • 1,000개 가상 단말 트래픽 발생기 (Simu-Traffic Gen v2.0)    │
│   - 음성 패킷 (RTP/MCPTT), 위치 데이터, 가상 CCTV 영상 전송   │
│ • 3D GIS 기반 통합 지휘 관제 웹 대시보드 (WebRTC/WebGL)       │
│ • AI-QoS & AGB 실시간 알고리즘 분석 모니터링 엔진            │
└──────────────────────────────────────────────────────────────┘
                         │ (10Gbps 광 링크 - VLAN 100/200)
                         ▼
[2. 실물 하드웨어 테스트베드 랙 (Hardware Rack Environment)]
┌──────────────────────────────────────────────────────────────┐
│ • ITS-GW100 산업용 RoIP 게이트웨이 (2대 - 이중화 구성)        │
│ • 3GPP 표준 MCPTT 코어 서버 (1U 랙마운트 어플라이언스)        │
│ • KCMVP 보안 IPSec VPN 게이트웨이                             │
└──────────────────────────────────────────────────────────────┘
                         │ (E&M Audio, RS-232, SIP, IP)
                         ▼
[3. 실물 엔드포인트 단말 군 (Real Endpoint Devices)]
┌──────────────────────────────┬───────────────────────────────┐
│ • 실물 PS-LTE 무전기 4대      │ • 실물 아날로그/디지털 VHF 2대│
│ • 실물 SIP 유선전화 2대       │ • 실물 지자체 IP 비상벨 1대   │
└──────────────────────────────┴───────────────────────────────┘
```

## 6.2. 3대 핵심 실증 시나리오 및 상세 시험 절차서 (Test Procedure)

### 6.2.1. [시나리오 1] 이종 유무선 단말 간 실시간 원터치 음성 교신 시현

[표 6-1] 시험 절차서 1: 이종 단말 간 원터치 음성 교신

| 항목 구분 | 세부 내용 및 기준 |
| :--- | :--- |
| **시험 항목** | 유선 행정전화 ↔ PS-LTE 무전기 ↔ 레거시 VHF 무전기 상호 연동 |
| **시험 목적** | 이기종 단말 간 양방향 PTT 통화 수립 시간 및 음질 검증 |
| **시험 절차** | 1. 유선 IP 전화기에서 비상 단축번호 '911' 입력 및 발신<br>2. ITS-GW100 게이트웨이가 SIP 호를 감지하고 E&M 신호 변환<br>3. 실물 PS-LTE 단말 4대 및 VHF 무전기 2대에서 동시 벨 출력<br>4. VHF 무전기에서 PTT를 누르고 음성 발신 ("현장 상황 보고")<br>5. 유선 전화기 및 PS-LTE 단말기에서 실시간 음성 수신 확인 |
| **합격 기준 (Pass/Fail)** | • 호 수립 지연시간: $T_{call\_setup} \le 300\text{ms}$<br>• 음성 전파 지연시간: $T_{voice\_latency} \le 150\text{ms}$<br>• 음성 명료도(MOS Score): $\ge 4.2$ (POLQA 표준 측정)<br>• 패킷 지터(Jitter): $\le 20\text{ms}$ |

### 6.2.2. [시나리오 2] 비상벨 연동 위치기반 자동 그룹 바인딩(AGB) 시현

[표 6-2] 시험 절차서 2: 위치기반 자동 그룹 바인딩 (AGB)

| 항목 구분 | 세부 내용 및 기준 |
| :--- | :--- |
| **시험 항목** | 현장 IP 비상벨 작동 시 인근 단말기 자동 바인딩 및 통화 |
| **시험 목적** | 긴급 상황 발생 시 수동 조작 없는 1초 이내 자동 결합 검증 |
| **시험 절차** | 1. 실물 IP 비상벨의 'SOS 비상 호출' 버튼 누름<br>2. AGB 엔진이 비상벨 GPS 좌표를 기반으로 R-Tree 공간 검색<br>3. 3D GIS 관제 화면에 비상벨 위치 적색 팝업 및 알람 발생<br>4. 반경 내 지정된 실물 PS-LTE 단말 2대에 강제 SIP INVITE<br>5. 단말기 자동 수신(스피커폰) 후 비상벨-단말-상황실 3자 동시 전이중(Full-Duplex) 음성 통화 개시 |
| **합격 기준 (Pass/Fail)** | • 비상벨 누름부터 전 단말 통화 연결까지: $\le 1.0\text{s}$<br>• 자동 그룹 생성 성공률: $100\%$ (10회 연속 시험)<br>• 3D GIS 화면 팝업 지연시간: $\le 500\text{ms}$ |

### 6.2.3. [시나리오 3] 1,000개 노드 트래픽 폭주 시 AI-QoS 인명구조 통화 선점 시현

[표 6-3] 시험 절차서 3: 트래픽 폭주 시 AI-QoS 인명구조 선점

| 항목 구분 | 세부 내용 및 기준 |
| :--- | :--- |
| **시험 항목** | 네트워크 99% 포화 상태에서 비상 통화 100% 무중단 보장 |
| **시험 목적** | 대규모 재난 시 AI 기반 동적 대역폭 선점(ARP) 알고리즘 검증 |
| **시험 절차** | 1. S/W 발생기로 1,000개 가상 노드에서 대용량 영상/데이터 트래픽 주입 (네트워크 99% 포화 유발)<br>2. 관제 화면의 일반 CCTV 영상 스트리밍 끊김(Buffering) 확인<br>3. 실물 PS-LTE 단말에서 '긴급 비상 PTT(Emergency Call)' 버튼 누름<br>4. AI-QoS 엔진이 일반 트래픽 대역폭을 즉각 강제 회수<br>5. 비상 음성 패킷을 Class 1 큐로 직행시켜 0% 손실 전송 확인 |
| **합격 기준 (Pass/Fail)** | • 비상 음성 패킷 손실률(Packet Loss Rate): $0.0\%$<br>• 긴급 통화 발언권 획득 시간: $\le 100\text{ms}$<br>• 일반 트래픽 자동 제한(Throttling) 반응 시간: $\le 50\text{ms}$ |

### 6.2.4. [시나리오 4] 정부 화상회의망(H.323/SIP) ↔ 현장 MCVideo/CCTV 다자간 실시간 화상 연계 시현

[표 6-4] 시험 절차서 4: 정부 화상회의망과 현장 영상 다자간 실시간 연계

| 항목 구분 | 세부 내용 및 기준 |
| :--- | :--- |
| **시험 항목** | 정부 재난 화상회의 시스템 ↔ 현장 PS-LTE MCVideo 및 지자체 CCTV 실시간 다자간 화상 연계 |
| **시험 목적** | 지휘관 화상회의 화면에 현장 바디캠/CCTV 영상을 실시간 PIP로 브리지하여 영상 사각지대 해소 검증 |
| **시험 절차** | 1. 상황실 H.323/SIP 화상회의 단말에서 긴급 화상회의 세션 개설<br>2. Video IWF 게이트웨이가 현장 PS-LTE 단말 MCVideo 스트림 및 인근 CCTV WebRTC 영상을 H.264/SIP로 트랜스코딩<br>3. 정부 화상회의실 메인 화면에 현장 소방관 시야 영상 및 CCTV 영상이 300ms 이내 PIP로 실시간 공유<br>4. 다자간 영상/음성 양방향 소통 품질 검증 |
| **합격 기준 (Pass/Fail)** | • 화상 스트림 변환 및 전송 지연시간: $T_{video\_latency} \le 300\text{ms}$<br>• 화상회의 화면 동기화 지연(AV Sync): $\le 50\text{ms}$<br>• 영상 패킷 손실률(Video Packet Loss): $\le 0.1\%$<br>• 영상 품질(VMAF): $\ge 85$ 점 (FHD 1080p 기준) |
